# linguagens_de_programacao
Repositório para as aulas de Linguagens de Programação



//Classe: é o molde usado para criar objetos. Exemplo: Carro.
//Objeto: é algo criado a partir de uma classe. Exemplo: meuCarro.
//Método: é uma ação que o programa executa. Exemplo: acelerar().
//Atributo: é uma característica do objeto. Exemplo: cor.
//Construtor: inicializa o objeto quando ele é criado. Exemplo: new Carro().
Para memorizar: classe é o molde, objeto é o elemento criado e método é a ação.

O que significa cada parte?
- main: em Java é ser o ponto de entrada do programa, ou seja, é por onde a execução começa.
- public: pode ser acessada pela JVM.
- static: pode ser executada sem criar um objeto da classe.
- void: não retorna nenhum valor.
- main: nome do método principal.
- String[] args: recebe argumentos passados ao programa.
Para memorizar para a prova: a main é o método principal por onde o programa Java começa a executar.

Tipo	          Como funciona	                                              Exemplo
Snake Case	    Palavras separadas por _	                                  nome_completo
Camel Case	    Primeira palavra minúscula; próximas começam com maiúscula	nomeCompleto
Pascal Case	    Todas as palavras começam com maiúscula	                    NomeCompleto

Em Java, a convenção mais comum é:
- Variáveis e métodos: camelCase
- Classes: PascalCase
- Constantes: SNAKE_CASE com letras maiúsculas.
